# Control Deck

Нативный WPF-MVP для Windows 10/11 на .NET 10. Проект собирается без обязательных внешних сервисов.

## Возможности

- смена обоев рабочего стола через системный API;
- запуск Steam, Wallpaper Engine, Проводника и настроек Windows;
- переход к настройкам русской речи и диктовке Windows (`Win + H`);
- встроенный список процессов с обновлением и быстрый запуск Task Manager;
- запуск AMD Software: Adrenalin Edition, если оно установлено;
- локальная папка профилей для будущих сетевых настроек.

Разгон видеокарты намеренно не выполняется автоматически: напряжения и частоты меняются только пользователем в официальной утилите AMD. Сетевой модуль не содержит списков обхода или удалённого управления.

## Запуск

```powershell
dotnet run --project .\ControlDeck\ControlDeck.csproj
```

## Сборка

```powershell
dotnet build .\ControlDeck\ControlDeck.csproj
```
